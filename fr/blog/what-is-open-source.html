Qu'est-ce que l'open source ?

L'open source (source ouverte) signifie que le code source d'un logiciel est accessible publiquement. N'importe qui peut le voir, l'étudier, le modifier et le redistribuer, généralement gratuitement.

Cela contraste avec le logiciel propriétaire, où le code est secret – vous achetez le droit d'utiliser le logiciel compilé, mais vous ne voyez jamais comment il fonctionne. Microsoft Windows est propriétaire. Adobe Photoshop est propriétaire. Vous les achetez mais vous ne pouvez pas voir ou modifier le code.

L'open source est basé sur l'idée que les logiciels de meilleure qualité et plus sûrs résultent de la collaboration ouverte. Si mille yeux examinent le code, les bugs sont trouvés plus rapidement. Si quelqu'un veut faire quelque chose de différent avec le logiciel, il peut.

Le terme "open source" est relativement nouveau (années 1998), mais l'idée des logiciels libres est bien plus ancienne, remontant aux premières communautés informatiques académiques.

Licences open source

"Open source" ne signifie pas nécessairement "gratuit" dans le sens du prix. Cela signifie que le code est ouvert. Mais il y a des conditions – les licences open source.

GPL (GNU General Public License) : La licence open source la plus courante. Si vous modifiez le code GPL, vous devez partager vos modifications avec le monde. C'est ce qu'on appelle "copyleft" – une tournure de "copyright". Linux fonctionne sous GPL.

MIT License : Très permissive. Vous pouvez prendre le code, le modifier, le vendre, et vous n'avez besoin que de créditer l'auteur original. Beaucoup de projets populaires utilisent MIT.

Apache License : Similaire à MIT, mais avec une protection légale supplémentaire contre les poursuites en brevets.

BSD License : Très proche de MIT – simple et permissive.

En bref : GPL = vous devez rester open source. MIT/Apache/BSD = faites ce que vous voulez, tant que vous crédits l'auteur.

Exemples d'open source

Système d'exploitation : Linux est le plus grand projet open source au monde. C'est un système d'exploitation complet que vous pouvez utiliser gratuitement. Ubuntu, Fedora et Debian sont des distributions Linux basées sur le noyau Linux.

Serveurs web : Apache et Nginx alimentent une grande partie d'Internet. Ce sont les logiciels que les serveurs utilisent pour envoyer des pages web.

Navigateurs web : Firefox est entièrement open source. Chromium (le code source derrière Google Chrome) est également open source.

Base de données : MySQL et PostgreSQL sont d'énormes projets open source utilisés par des millions de sites web et d'applications.

Outils de développement : Git (le système de contrôle de version), Python (langage de programmation), Node.js et des milliers d'autres outils de développement populaires sont open source.

Bureau et productivité : LibreOffice est une suite open source équivalente à Microsoft Office. GIMP est un éditeur d'images open source similaire à Photoshop (bien que moins puissant).

VLC Media Player : Un lecteur multimédia open source qui joue presque n'importe quel format vidéo ou audio.

Avantages du logiciel libre

Sécurité : Avec des milliers de yeux sur le code, les vulnérabilités de sécurité sont trouvées plus rapidement. Les attaquants savent que le code sera scruté, ce qui crée une incitation à le corriger.

Coût : Beaucoup de logiciels open source sont gratuits. Même les services professionnels construits sur l'open source (comme le support) coûtent généralement moins cher que les alternatives propriétaires.

Indépendance : Vous n'êtes pas enfermé par un fournisseur. Si l'entreprise derrière le logiciel ferme ou change ses prix de manière drastique, vous pouvez continuer à utiliser le logiciel (ou un fork – une copie modifiée).

Personnalisation : Si vous avez besoin d'une fonctionnalité spécifique, vous pouvez la coder vous-même ou embaucher quelqu'un pour le faire.

Transparence : Vous savez exactement ce que fait le logiciel. Pas de code secret qui suit vos données ou limite vos fonctionnalités.

Communauté : Beaucoup de projets open source ont des communautés dévouées qui aident, partagent des connaissances et contribuent.

Le mouvement français du logiciel libre

La France a une forte tradition d'open source et de logiciels libres. Framasoft est l'une des organisations les plus importantes.

Framasoft est une association française fondée en 2001 qui promeut les logiciels libres et les services en ligne décentralisés. Ils hébergent de nombreux services libres alternatifs :

  • Framapad – Alternative à Google Docs (documents collaboratifs)
  • Framaform – Alternative à Google Forms (sondages et formulaires)
  • Framadate – Pour coordonner les réunions
  • Framasoft wiki – Une collection de tutoriels et d'informations sur le logiciel libre

En France, il existe une sensibilité particulière à la vie privée et à la souveraineté numérique. Le gouvernement français encourage les ministères à utiliser du logiciel libre. L'armée française utilise Linux. Les écoles françaises enseignent de plus en plus Linux et les logiciels libres.

D'autres organisations françaises importantes incluent l'April (Association pour la Promotion et la Recherche en Informatique Libre) et des projets comme Libre Office qui ont des fortes contributions françaises.

Le message français est clair : les logiciels libres ne sont pas seulement techniquement supérieurs, ils sont importants pour l'indépendance numérique du pays.

Carrières en open source

L'open source crée des emplois. Même si le logiciel est gratuit, quelqu'un doit le maintenir. Les carrières en open source incluent :

Développeur open source : Écrire et maintenir du logiciel open source. Certains travaillent pour des entreprises (comme les développeurs de Google travaillant sur Android, qui est basé sur Linux). D'autres sont volontaires ou reçoivent des donations.

Consultant en open source : Aider les entreprises à mettre en œuvre des solutions open source.

Responsable de communauté : Gérer les contributions des communautés, examiner les demandes de fusion, et maintenir la culture du projet.

Responsable de support : Offrir un support technique pour les logiciels open source.

Les contributions open source sur votre CV sont très appréciées par les recruteurs. Cela montre que vous pouvez collaborer, coder, et participer à une communauté.

Questions fréquentes

Si c'est gratuit, comment les entreprises gagnent de l'argent ?

De plusieurs façons : support technique premium, formation, services d'hébergement, ou services de consultation. Par exemple, Red Hat vend du support pour Linux. Canonical vend du support pour Ubuntu. Le logiciel est gratuit, mais le service payant.

Open source signifie-t-il qu'il n'y a pas d'entreprises impliquées ?

Non. Beaucoup de grandes entreprises contribuent à l'open source. Google contribue à Linux. Microsoft contribue à .NET. Facebook contribue à React. Cela crée de meilleurs logiciels pour tout le monde.

Puis-je utiliser du logiciel open source commercialement ?

Oui, avec les licences permissives (MIT, Apache). Avec GPL, vous devez rendre votre code ouvert également. Lisez la licence avant d'utiliser.

L'open source est-il moins professionnel que les logiciels payants ?

Non. Certains des logiciels les plus importants et fiables au monde sont open source. Linux alimente les serveurs des plus grandes entreprises du monde.
